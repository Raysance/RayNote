# 技术说明

## 运行结构

当前实现复用本地 Raycast 1.104.31 的原生 Notes 模块和原版 Web 编辑器，由新增 Objective-C 宿主独立启动。仓库提供宿主、提取脚本和验证工具，没有恢复或包含原始 Swift 工程。

提取过程将原可执行文件转换为可加载的 `MH_BUNDLE`，保留原代码和数据布局，调整加载命令与 chained fixups。运行时通过 `dlopen` 加载 `NotesCore`，初始化原版 Application、Notes 窗口、控制器、主题提供器和所需服务，跳过完整启动器的启动流程。

原版二进制仍包含其他静态链接代码；没有将每一段无关机器码物理移除。宿主只启动 Notes 所需路径。

## 宿主适配

| 文件 | 用途 |
| --- | --- |
| `extract.py` | 复制资源、转换模块、应用固定地址修改、编译和签名 |
| `native_main.m` | 原生模块启动、主题初始化、目录隔离与网络限制 |
| `gui_support.h` | 应用生命周期、菜单与事件适配 |
| `native_settings.h` | 原版 Notes 设置提供器、列表容器与菜单栏入口 |
| `branding.h` | 窗口、菜单、工具提示和设置动作的显示名称适配 |
| `dependency_isolation.py` | 保持库序号，将两个无关框架及其导入标记为可选 |
| `audit_dependencies.py` | 有明确边界的机器码调用与编辑器资源依赖审计 |
| `prune_resources.py` | 资源包白名单、笔记图标裁剪与保留项验证 |
| `scripts/make-icon.swift` | 生成独立的笔记应用图标 |
| `credentials.m` | 独立生成的数据库和缓存密钥持久化 |
| `security_slots.h` | 原模块四个 Security 导入槽的地址 |
| `swift_bridge.S` | 带 Swift 上下文寄存器的内部函数调用桥 |
| `verify.py` | 指令、资源、哈希与签名校验 |

机器码清单共有 11 处修改，涉及 Notes 的本地数量限制、对应只读和升级分支，以及独立设置窗口入口。没有模拟服务器授权或解锁远端服务。

## 存储与网络

应用使用独立目录和新建的加密数据库，不读取原应用的笔记或系统钥匙串。四个 Security 导入调用适配为本地凭据文件，仅处理独立应用生成的数据库、缓存密钥。文件权限为 `0600`，数据目录为 `0700`。

该密钥文件没有系统钥匙串的访问保护，同一用户权限下的其他程序可能读取它。备份必须包含密钥和数据库。损坏或缺失密钥时拒绝启动，以避免生成新密钥覆盖旧数据。

0.2 将应用显示名称、主程序和核心文件名改为 RayNote / NotesCore。数据目录和 bundle identifier 保持兼容，凭据适配器将新显示名映射到既有密钥命名空间，避免重新生成密钥。显示名称适配不改写笔记正文，也不批量修改原模块的类名或运行时符号。

0.3 仅保留 Web 编辑器资源包、emoji 数据、63 个笔记及通用操作图标和独立应用图标。编辑器自身包含 Highlight.js 和四个 WOFF2 字体；额外的原生语法高亮包、MathJax 包、GRDB 的隐私资源包和根目录 OTF/TTF 字体已移除。`assetutil` 的保留列表长度存在限制，构建时限制参数长度并逐项验证保留图标，防止静默丢失资源。

宿主应用进程禁止网络访问，并禁止读写原 Raycast 数据目录及写入原应用。云同步和 AI 不可用。

## 验证和边界

39,207,872 字节原生代码除清单记录的修改外与输入二进制一致，编辑器 HTML、JS、CSS 和字体资源逐文件一致。此前版本验证包括八条笔记、较早笔记仍可编辑和快速退出后恢复。0.3 重新验证中文和富文本保存、代码高亮、查找、复制笔记、HTML / Markdown 导出、既有数据库恢复、全新数据库初始化和重启、Notes 设置。

此前在原 Raycast 主进程挂起时，独立应用仍成功新建和编辑笔记。运行时加载的核心来自独立应用自身。0.3 不再包含 SplineRuntime 和 SoulverCore，两个加载命令及其 455 个导入被标记为可选，其余导入和库序号保持原值。实际进程检查未加载这两个框架或原应用文件。

静态分析追踪 6,240 个通过直接分支可达的函数，未发现上述框架的直接引用。间接调用、回调、元数据和计算地址仍有未覆盖路径，不能将零引用解释为全程序无依赖证明。逐项证据见 [资源依赖说明](DEPENDENCIES.md) 和 [静态报告](DependencyAudit.json)。

尚未完整迁移或验证启动器的全局快捷键、Quicklinks、深链接，以及所有边界行为和长期稳定性。应用生命周期和部分事件处理由宿主接管，不能据此宣称整个原应用的行为完全相同。

内部函数地址与指定输入构建绑定，后续升级需要重新分析和验证。当前构建仅在本机 arm64 macOS 27.0.1 实测。

之前的 SwiftUI 实现在 Git 历史中保留；它的 JSON 笔记和备份机制不适用于当前实现，也没有自动迁移程序。
