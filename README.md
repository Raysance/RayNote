# RayNote

随时打开，随手记录。RayNote 将浮动笔记窗口、富文本编辑和快捷搜索放在一起，笔记自动保存在本机。

## 开始使用

将 `RayNote.app` 拖入“应用程序”文件夹，打开即可写作。

## 编辑与整理

- 新建多篇笔记，在笔记列表中搜索和切换。
- 为文字设置加粗、斜体、下划线和字号。
- 置顶常用笔记，通过菜单栏控制窗口。
- 编辑内容自动保存，打开应用即可接着写。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `⌘ N` | 新建笔记 |
| `⌘ F` | 打开笔记切换和搜索 |
| `⌘ Return` | 将焦点移到编辑器 |
| `⌘ ⇧ P` | 置顶或取消置顶当前笔记 |
| `⌘ B` | 加粗 |
| `⌘ I` | 斜体 |
| `⌘ U` | 下划线 |
| `⌘ +` / `⌘ -` | 增大或减小所选文字 |
| `⌘ ⌥ ↑` / `⌘ ⌥ ↓` | 选择上一条或下一条笔记 |
| `⌘ ⇧ Delete` | 删除当前笔记 |

## 备份与恢复

退出 RayNote 后，复制整个笔记目录：

```text
~/Library/Application Support/RayNote/
```

恢复或换机时，退出应用，将完整备份放回同一路径，再打开 RayNote。

应用还会自动保存当前镜像和最近 20 份历史备份，位于 `~/Library/Application Support/RayNote/Backups/`。
